# Qadi — دليل العطور

تطبيق جوال (Expo / React Native) لاستكشاف العطور وبناء مجموعتك الشخصية.

## الموجود حالياً

- **استكشف**: قائمة عطور مع بحث بالاسم أو الماركة أو النوتة، وفلترة بالعائلة العطرية.
- **صفحة العطر**: الهرم العطري (عليا / قلب / قاعدة)، تقييم بالنجوم، وإضافة إلى «عندي» أو «أتمناه».
- **مجموعتي**: عطورك وقائمة أمنياتك، محفوظة على الجهاز.

البيانات حالياً عيّنة ثابتة في `src/data/perfumes.ts`، والتقييمات والمجموعة محلية على الجهاز فقط
(`src/store/collection.tsx`) — ما فيه حسابات ولا خادم بعد.

## التشغيل

```bash
npm install
npx expo start        # ثم افتحه في Expo Go أو اضغط w للمتصفح
npx tsc --noEmit      # فحص الأنواع
```

الواجهة عربية ومن اليمين لليسار. على الجوال يتفعّل اتجاه RTL من ثاني تشغيل بعد التثبيت.
